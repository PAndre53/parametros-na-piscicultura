# parametros-na-piscicultura
O problema: Variações bruscas na qualidade da água dos tanques (como oxigênio baixo ou temperatura inadequada) podem dizimar uma produção inteira de tambaqui em poucas horas. 

O que o app deve gerenciar: Histórico de medições diárias (pH, temperatura, oxigênio), registro de mortalidade e alertas visuais de parâmetros fora do limite ideal.
